Types of Birds Website
About This Project
I created this website to share information about different types of birds, including lovebirds, peregrine falcons, crows, hyacinth macaws, and Argentavis magnificens.

I originally built the website using HTML and CSS. Later, I redesigned it in Figma to improve the colors, spacing, navigation, and overall layout.

Technologies Used
HTML5
CSS3
Figma
Git and GitHub Pages
What I Worked On
Redesigned the website layout in Figma.
Organized bird pictures and descriptions to make the information easier to follow.
Improved the colors, spacing, and readability.
Updated the HTML and CSS to match the new design.
Published the website using GitHub Pages.
What I Learned
This project helped me improve my HTML and CSS skills. I also learned how to redesign an existing website, make the layout more consistent, and publish updates using GitHub.
